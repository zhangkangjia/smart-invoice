# 企业微信集成指南

## 应用场景

将智能开票平台作为企业微信自建应用嵌入到企业微信工作台，代账人员无需单独登录账号，在企业微信里直接打开使用，开票完成后自动推送通知到企业微信。

## 前置准备

1. 已注册企业微信管理员账号
2. 已备案企业微信 CorpID
3. 已创建自建应用（用于嵌入系统）

## 一、创建企业微信自建应用

1. 登录企业微信管理后台：https://work.weixin.qq.com/wework_admin/
2. 进入「应用管理」→「自建应用」→「创建应用」
3. 填写应用信息：
   - 应用名称：智能开票
   - 应用 Logo：上传
   - 应用介绍：智能开票平台，支持文字/图片/Excel多种方式开票
4. 设置应用主页 URL：
   ```
   http://your-domain.com:3000/wecom-callback
   ```
5. 设置可信域名：填入你的域名
6. 记录以下信息：
   - **CorpID**（我的企业 → 企业信息）
   - **AgentID** 和 **Secret**（自建应用详情页）

## 二、配置 .env 环境变量

在项目根目录的 `.env` 文件中配置：

```env
# 企业微信
WECOM_CORP_ID=ww1234567890abcdef
WECOM_AGENT_ID=1000002
WECOM_SECRET=your_app_secret_here

# 前端访问地址（用于回调和通知链接）
FRONTEND_BASE_URL=http://your-domain.com:3000
```

重启服务使配置生效：

```bash
./deploy.sh pull
```

## 三、绑定系统用户

代账人员首次使用时，管理员需要把系统用户与企业微信 userid 绑定：

1. 用管理员账号登录系统
2. 进入「系统管理」→「用户管理」
3. 给每个用户绑定企业微信（通过企业微信通讯录同步或手动输入 userid）
4. 也可通过 API 批量绑定：

```bash
curl -X POST http://localhost:8000/api/v1/wechat/wecom/bind-user \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "系统用户ID", "wecom_userid": "企业微信userid"}'
```

## 四、配置工作台

在企业微信管理后台 → 应用详情 → 「网页授权及 JS-SDK」：

- **OAuth 授权回调域**：填入你的域名（不带 http://）
- **JS-SDK 可信域名**：同上

## 五、使用流程

### 代账人员侧
1. 打开企业微信 → 底部「工作台」→ 找到「智能开票」应用
2. 点击进入，自动登录（无需输入账号密码）
3. 正常使用开票功能

### 客户侧
客户收到开票完成通知（推送至企业微信），点击进入查看发票详情。

## 六、通知推送

开票任务完成（成功/失败）时，系统自动通过企业微信应用消息推送给 @all 成员。

如需自定义推送对象（按企业、按人），可在 `backend/app/api/v1/business_requests.py` 的 `_execute_invoice` 函数中修改 `user_ids` 参数。

## 七、可选：工作台应用图标

如需在工作台显示应用图标，上传企业 Logo 至应用详情页即可。

## 八、故障排查

**1. 点击应用提示"redirect_uri 域名与后台配置不一致"**
- 检查企业微信管理后台 → 应用详情 → 网页授权及 JS-SDK → OAuth 授权回调域
- 必须是完整域名，不能带 http:// 或路径

**2. 提示"该企业微信账号未绑定系统用户"**
- 在用户管理中绑定 userid 和 wecom_userid

**3. JS-SDK 签名失败**
- 检查 `WECOM_CORP_ID` 和 `WECOM_SECRET` 是否正确
- 调用 `/api/v1/wechat/wecom/jsapi-config?url=完整URL` 重新生成签名

## 九、相关 API

| 端点 | 说明 |
|------|------|
| `GET /api/v1/wechat/wecom/oauth-login?code=xxx&redirect=/` | OAuth 免登录 |
| `GET /api/v1/wechat/wecom/jsapi-config?url=xxx` | JS-SDK 配置 |
| `POST /api/v1/wechat/wecom/bind-user` | 绑定企业微信 userid |
| `GET /api/v1/wechat/wecom/department-users?department_id=1` | 同步部门成员 |
| `POST /api/v1/wechat/notify-invoice` | 内部调用，推送开票通知 |
| `GET /api/v1/wechat/status` | 查看集成状态 |
